# Meat Math

A protein-first meat calculator for busy people.

Pick a protein target for one meal and see the approximate raw and cooked portions for common cuts of beef, poultry, pork, lamb, and fish.

## Why

Protein goals are easier when the first question is already answered:

> how much meat do I need on my plate?

This tool is for groceries math, meal prep, and tired-parent plate planning.

## Features

- Protein target input, defaulting to `30g`
- Raw and cooked portion estimates
- Grams / ounces toggle
- Meat category filters
- Search by cut
- Sort by cooked portion, raw portion, protein efficiency, or name
- Copyable meal math for planning
- Single HTML file, no build step

## Notes

Nutrition values are approximate per 100g from USDA FoodData Central entries and vary by cut, source, trimming, and cooking method. Mercury notes follow FDA/EPA advice about eating fish.
